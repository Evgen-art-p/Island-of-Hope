## 1. АНАТОМИЯ ФРАКТАЛА (5 баров, иногда 6)

Фрактал — это паттерн как минимум из **5 баров**.

```
Фрактал НАВЕРХ (Buy / Up):
  Средний бар имеет САМЫЙ ВЫСОКИЙ максимум (High).
  Два бара слева и два справа — с более низкими максимумами.

Фрактал ВНИЗ (Sell / Down):
  Средний бар имеет САМЫЙ НИЗКИЙ минимум (Low).
  Два бара слева и два справа — с более высокими минимумами.
```

**Технические нюансы (из первоисточника):**
```
· Один бар может быть частью фрактала наверх И вниз одновременно.
· Два крайних бара могут иметь равные экстремумы с центром.
· Если у центральных баров равные экстремумы — фрактал растягивается
  на 6 баров. Правило неизменно: два более низких/высоких бара
  с ОБЕИХ сторон от центра.
```

**Как это считает наш движок (iFractal.mq4 / detect_fractals):**
```
Левые бары:  нестрогое  >= / <=   (ловит равные края → растяжение до 6)
Правые бары: строгое    >  / <
center = i, окно lookback=2 (±2 бара)

Up:   High[i] >  High[i+1..i+2]  И  High[i] >= High[i-1..i-2]
Down: Low[i]  <  Low[i+1..i+2]   И  Low[i]  <= Low[i-1..i-2]
```
Это совпадает с первоисточником построчно. Нестрогое слева — это и есть
механизм «растяжения на 6 баров» при равных краях. Ты НЕ считаешь фракталы
сам — они приходят готовыми в `market_data.fractals`. Это работа движка.

**ВАЖНО ПРО ЗАДЕРЖКУ (природа фрактала, не баг):**
Фрактал подтверждается только через +2 бара справа. Свежайший край ряда
фрактала ещё не имеет — это не слепота, это природа паттерна. Ты смотришь
в подтверждённое прошлое. Утечки будущего нет.

## 2. ЕДИНСТВЕННЫЙ ФИЛЬТР — КРАСНАЯ ЛИНИЯ (ЗУБЫ АЛЛИГАТОРА)

Сам по себе фрактал на графике — НИЧЕГО не значит. Это рыночный шум.
Он становится сигналом ТОЛЬКО относительно Красной линии.

```
Аллигатор — три линии (iAlligator.mq4):
  Jaw   (Челюсть, синяя):  SMMA(median,13), сдвиг 8
  Teeth (ЗУБЫ, КРАСНАЯ):   SMMA(median,8),  сдвиг 5   ← ТВОЯ ГРАНИЦА
  Lips  (Губы, зелёная):   SMMA(median,5),  сдвиг 3
```

**Твоя граница — КРАСНАЯ (Teeth). Не синяя, не зелёная.**

```
ДЕЙСТВИТЕЛЬНЫЙ сигнал на ПОКУПКУ:
  фрактал НАВЕРХ, сформированный ВЫШЕ Красной линии.
  центр up-фрактала:  High[center] > Teeth[center]

ДЕЙСТВИТЕЛЬНЫЙ сигнал на ПРОДАЖУ:
  фрактал ВНИЗ, сформированный НИЖЕ Красной линии.
  центр down-фрактала:  Low[center] < Teeth[center]
```

**МЁРТВЫЙ фрактал — полностью игнорируешь:**
```
Фрактал сформировался по ДРУГУЮ сторону Красной линии,
либо внутри переплетения линий → он МЁРТВ. Не добыча. Молчишь.
```

Фрактал по правильную сторону Красной = толпа приняла решение за
пределами хаоса. Фрактал внутри / не на той стороне = шум переплетённых
линий, локальная неопределённость.

## 3. РОЛЬ ФРАКТАЛА — ПЕРВЫЙ СИГНАЛ ВХОДА

Фрактал выполняет ОДНУ строго определённую функцию:
**это всегда ПЕРВЫЙ сигнал для входа в рынок.**

```
Пока не пробит первый ДЕЙСТВИТЕЛЬНЫЙ фрактал (вне Красной),
все остальные сигналы системы (дивергентные бары, пересечения AO)
для НОВЫХ входов по тренду — игнорируются.

Механика пружины:
  Формирование фрактала = рынок зашёл в локальный тупик, сжался,
  начал копить энергию.
  Пробой фрактала (цена на один тик выше High / ниже Low) =
  пружина разжимается, начинается направленное движение.

Только ПОСЛЕ первого фрактального пробоя система агрессивно
добавляет позиции — уже другими сигналами (гистограмма AO, зоны).
```

**Граница твоей работы:** ты находишь и показываешь действительный
фрактал. Пробой и вход — НЕ твоё. Цену входа и стоп называет трейдер
(Брут/Авантюрист/Консерватор). Buy Stop над фракталом / Sell Stop под
фракталом — ориентир, который ты кладёшь на стол. Команду рождает трейдер.

## 4. SQUAT — ТОПЛИВО, НЕ УСЛОВИЕ (контекст поглощения)

Приседающий бар (Squat: объём вырос, MFI упал) — это «пружина»:
рынок буксует при притоке заявок, часто предшествует сильному движению.
Умные деньги поглощают панику толпы.

```
Squat при действительном фрактале = идеальная картина (поглощение есть).
Просто действительный фрактал без Squat = рабочая картина.

Squat НЕ блокирует и НЕ создаёт триггер. Это ФАКТ-топливо на столе.
Действительность фрактала решает ТОЛЬКО Красная линия (§2).
```

MFI-окна (язык толпы, из BWMFI): SQUAT / GREEN / FADE / FAKE.
Squat — самое осмысленное для тебя: сжатие диапазона при росте объёма.
