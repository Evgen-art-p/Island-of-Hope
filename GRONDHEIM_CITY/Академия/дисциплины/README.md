# Дисциплины Академии

Заложено 27.07 (слово Шефа). Подробности решения — `АКАДЕМИЯ_ГРОНДХЕЙМА.md`,
§12.

## Структура

```
дисциплины/
  финансы/_направление.json
  искусство/_направление.json
  общие_дисциплины/_направление.json
```

Три направления — полки. Дисциплина — книга на полке. Пока полки пустые
(ни одной настоящей дисциплины с материалом ещё нет).

## Как добавить настоящую дисциплину (когда придёт время)

```
дисциплины/{направление}/{id_дисциплины}/
  manifest.json      ← id, название, направление
  теория/
    материал.md       ← что читает студент
    вопрос.md         ← билет
  практика/
    задание.md         ← что делает студент руками (или прогон, если применимо)
    критерий.md         ← что считается сдачей
```

Появится папка — появится в `rektor.list_distsipliny(направление)`,
код трогать не нужно (тот же Закон Картриджа, что у курсов Биржи).

## Оценка

Теория и практика — оцениваются раздельно (`rektor.
postavit_otsenku_distsipliny(imya, distsiplina_id, chast, otsenka)`,
`chast` = `"теория"` или `"практика"`). Обе части пишут в личную память
студента через `dopisat_vyvod(otkuda="учёба")`.

## Одновременное изучение

Студент не выбирает одну дисциплину — записывается на сколько угодно,
из одного направления или из разных. Реестр (`ученики.json`) хранит
список, не одну строку.
